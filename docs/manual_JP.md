# Signal-Sketch 使い方

音響・映像・制御・ネットワークのシステム構成図を作るアプリです。機器を置き、ポート同士をマウスでつなぐと、線が自動で引かれ、信号の種類ごとに色が付きます。

## 1. 起動

- `index.html`(1ファイル)をダブルクリックして、ブラウザで開きます。
- インストールは要りません。Webサーバも、ネットワーク接続も要りません。
- **Edge または Chrome を推奨**します。保存ダイアログを使えるためです。Firefox・Safari では、保存がダウンロードになります(動作は未検証)。
- 図のデータは、パソコンの中だけで扱います。外部へは送りません。
- 起動したときは、空の図です。サンプルの図 [docs/sample_diagram.json](sample_diagram.json) は、「開く」で読み込めます(サンプルの機器名・型番はすべて架空です)。

## 2. 画面

| 場所 | 内容 |
|---|---|
| 上部 | ツールバー(新規・開く・保存・各種出力・機器一覧の読み込み・確認事項・元に戻す・やり直し・削除・グリッド吸着・拡大縮小・言語切替・配色切替) |
| 左 | パレット(枠・標準の機器・この図の機器) |
| 中央 | 図(初期は1280×720、16:9。大きさは変えられます)。下に凡例 |
| 右 | プロパティ(選んだものの設定。何も選んでいないときは、確認事項と凡例の編集) |

初回の起動時は、ブラウザの第一言語に合わせます(日本語なら日本語、それ以外は英語)。ツールバーの「English / 日本語」で切り替えると、その選択が記憶され、以降はそちらが優先されます。切り替わるのは画面の文言だけで、入力した機器名や型番は変わりません。

画面の配色は、ツールバーの「表示」ボタンで切り替えます。押すたびに「自動(OSのライト/ダーク設定に従う)」「ライト」「ダーク」の順に変わります。選んだ配色は記憶されます(「自動」は記憶せず、OSの設定にそのまま従います)。配色が変わるのは画面だけで、書き出す SVG・PNG の画像は常に明るい配色です。ダークでは、暗い信号の色(濃い紫など)が見えにくくならないよう、画面の上でだけ少し明るく表示します。保存される色や書き出す画像の色は変わりません。

### 表示の拡大・縮小

- ツールバーの「縮小」「拡大」(25%〜300%)、「100%」(等倍に戻す)、「全体表示」(図全体が画面に収まる大きさにする。拡大はしません)で変えます。
- **Ctrl+ホイール**は、カーソルの位置を中心に拡大・縮小します(トラックパッドのピンチも同じ)。ふつうのホイールはスクロールです。**中ボタンのドラッグ**でも表示位置を動かせます。
- 拡大縮小は表示だけの設定です。図のデータ、保存する内容、SVG/PNG/CSVの出力は変わりません。

### ページの大きさ

機器が収まりきらないときは、ページ(図の領域)を大きくできます。何も選んでいない状態で、右パネルの「ページの大きさ」を使います。

- **標準**: 1280×720 / 1920×1080 / 2560×1440(いずれも16:9。PowerPointのスライドと同じ比率です)。
- **自由に指定**: 「自由に指定」を選ぶと、幅・高さを数値で入力できます(幅640〜4000、高さ360〜4000。グリッドの倍数に丸められます)。16:9以外の比率も使えます。
- 大きくすると、スライドに貼ったときに文字が相対的に小さくなります。
- 小さくできるのは、機器・枠がすべて収まる範囲までです。はみ出すものがあると、大きさは変わらず、右上にその名称が表示されます。
- 変更は「元に戻す」で戻せます。大きさは保存され、SVG/PNGの出力もこの大きさになります。

## 3. 機器を置く

- パレットの項目を**クリック**すると、空いている場所に追加されます。**ドラッグ**すると、好きな場所に置けます。
- 標準の機器は、汎用機器、PC、タッチパネル、カメラ、マイク、スピーカ、アンプ、ディスプレイ、エンコーダ、デコーダ、スイッチ(8/16/24/48ポート)です。
- 機器は、ドラッグで動かせます。位置と大きさは、**10pxのグリッド**に吸着します(ツールバーの「グリッド吸着」で切り替え)。
- 機器を選ぶと、右のパネルで、**名称・型番・台数**を編集できます。値は、入力欄を離れるか Tab を押したときに確定します。

### 複数の機器を一度に置く(一列に並べる)

- パレットの機器を **Shift を押しながらドロップ**すると、「一列に並べて追加」の画面が開きます。**個数**(1〜99)、**向き**(横/縦)、**間隔**(px)を決めて「追加」を押すと、ドロップした位置を先頭に、同じ名称の機器が一列に並びます。
- 間隔は最小値です。グリッド吸着が有効なときは、全員がグリッド上に乗るよう、刻みがグリッドの倍数に切り上げられます。
- 列がページの端からはみ出す位置にドロップしたときは、内側に寄せて置きます。列そのものがページに収まらないときは追加せず、理由が右上に出ます。
- 追加した機器はすべて選ばれ、「元に戻す」1回でまとめて消せます。直前に使った個数・向き・間隔は、次に開いたときの初期値になります。枠は対象外です。

### 複数の機器を選ぶ・まとめて消す

- **何もない場所をドラッグ**して囲むと、枠の中に**完全に収まった**機器・枠・線が選ばれます(触れただけでは選ばれません)。枠(グループ)の内側の空き地からは始められません(枠の移動になるため)。枠の外から囲んでください。
- **Ctrl(Mac は Cmd)または Shift を押しながらクリック**すると、選択に足す/外すことができます。**Ctrl+A** で、すべてを選びます。
- 2件以上を選ぶと、右のパネルに件数が出ます。**Delete**(または「削除」)でまとめて削除でき、「元に戻す」1回で戻せます。コピー・複製(次の節)も、選んだものすべてに効きます。
- 機器を2台以上選ぶと、右のパネルに「揃える・等間隔」のボタンが出ます。**左揃え・左右中央・右揃え・上揃え・上下中央・下揃え**は、選んだ機器全体を囲む長方形に合わせます。**左右に等間隔・上下に等間隔**は3台以上で使え、両端の機器は動かさず、機器どうしの間の空きを等しくします。グリッド吸着がオンのときは、結果の位置がグリッドに合わせて丸められます(中央揃えと等間隔は、最大でグリッド幅の半分ずれることがあります)。枠は動きません。「元に戻す」1回で戻せます。
- Shift を押しながら何もない場所をドラッグすると、機器ではなく**ポート**を選びます(「まとめて接続する」を参照)。

### 右クリックメニュー

図の上で右クリックすると、その場で操作を選べるメニューが出ます(ショートカットやパネルのボタンと同じ操作です)。

- **機器・枠・線の上**: コピー・複製・削除。機器を2台以上選んでいるときは、揃え・等間隔も出ます(等間隔は3台以上で使えます)。選んでいないものを右クリックすると、そのものだけを選んでから開きます。すでに選んでいるもの(複数でも)の上なら、選択はそのままです。
- **何もない場所**: 貼り付け(コピーした内容があるとき)・すべて選択。
- 閉じるには、Esc、メニューの外のクリック、スクロールやウィンドウの大きさの変更です。キーボードでは、↑↓・Home・End で項目を選び、Enter で実行できます。
- パネルやツールバー、ダイアログの上では、ブラウザ標準のメニューのままです。

### コピー・複製

- 機器または枠を選び、**Ctrl+C** でコピー、**Ctrl+V** で貼り付けます。**Ctrl+D** で、その場に複製できます。
- 名称・型番・台数・ポート構成・ポート位置が、そのまま引き継がれます。コピーした機器どうしの接続も、一緒にコピーされます(外の機器への接続は、コピーされません)。
- 機器は、右下へ少しずつずれて貼り付けられます。枠は、中の機器ごとコピーされ、なるべく他の機器や枠と重ならない位置に貼り付けられます。
- Ctrl を押しながらのドラッグは、複製ではなく、ふつうの移動です。コピーは、同じ画面の中だけで使えます(別のウィンドウへは貼れません)。

### 台数が複数の機器

台数を2以上にすると、**台数ぶんのポート**が表示されます。台ごとに別の行き先へつなげます。ツールチップには「LAN(3台目)」のように、何台目かが出ます。台数を減らして、接続のあるポートがなくなるときは、確認が出ます。

台数は**1〜999**、ポートの合計(台数ぶんを含む)は**1機器あたり5000まで**です。超える値は受け付けません(画面が固まるのを防ぐための上限です)。上限を超える図のファイルは、読み込めません。

## 4. ポートの設定

機器を選ぶと、パネルの「ポート」に、ポートの**グループ**が並びます。グループごとに次を設定します。

| 項目 | 内容 |
|---|---|
| 信号 | 信号の種類。線とポートの色が決まります |
| 方向 | 入力 / 出力 / 入出力。マークの形で区別します(入力=内向きの三角、出力=外向きの三角、入出力=菱形) |
| 位置 | 機器の左・右・上・下のどの辺に並べるか |
| 数 | ポートの数 |
| 接続 | 「1本まで」または「複数可」(通常は1本まで) |
| 表示名 | ポートの名前。ポートが1つだけなら番号なし(「LAN」)、2つ以上なら番号付き(「LAN 1」) |

- 「ポートを追加」で、グループを足せます。変更はその機器だけに効きます。同じ種類の他の機器は変わりません。
- ポートのマークは、空きなら白抜き、接続済みなら信号の色で塗りつぶされます。ポートに**マウスを合わせる**と、名前が出ます。
- **ポートを1つずつ動かす**: Shift を押しながらポートをドラッグします。最も近い辺の、グリッド上の位置に置かれます。別のポートと同じ場所へは置けません。パネルの「ポート位置を自動配置に戻す」で、元に戻せます。

## 5. 接続する

- 一方のポートから、もう一方のポートへドラッグします。線は、直角に自動で引かれます。
- **1つのポートに引ける線は1本**です(「複数可」にしたポートを除く)。
- 接続のドラッグ中は、**つなぎ先の候補**(同じ信号の種類で、空いているポート)に青い輪が付き、ほかのポートは薄くなります。接続済みのポートから始めたときは、候補が無いので、すべて薄くなります。信号が違うポートや入力同士へも、つなぐこと自体はできます(警告つき)。
- ポートにマウスを合わせると、信号の色の淡い輪で少し大きく表示されます。
- 同じポート同士、すでにある接続と同じ組み合わせは、つなげません。理由は、画面右上に数秒だけ出ます。
- 線を選んで「削除」(または Delete キー)で消せます。機器を消すと、つながる線も消えます。
- 線の色は、出力側ポートの信号の種類で決まります。

### まとめて接続する(複数のポートを一度に)

台数が複数の機器や、スイッチのように同じポートが並ぶ機器を、1回の操作でつなげます。

1. 何もない場所(枠(グループ)の内側の空き地でも可)から **Shift を押しながらドラッグ**して枠を引きます。枠に触れたポートが選ばれ(橙の輪)、機器をまたいでも選べます。
2. 選んだポートの**どれかをドラッグ**して、つなぎたい側のポートに落とします。
3. 選んだポートは「上から下、左から右」の順に、落とした先のポートから**順に1対1**でつながります(相手は、同じ機器の同じポートグループの中で、落とした先以降の空きポートです)。
4. ドラッグ中は、つなぐ組が点線で、つなげないポートが赤い輪と×で示されます。右上の表示は「何本つなぐか」を示します。
5. 落とすと、まとめて接続されます。**元に戻す(Ctrl+Z)は1回**で全部戻ります。

**落とした先の機器が枠(グループ)の中にあるときは、同じ枠の中の別の機器へも進みます。** 落とした機器のポートを使い切ると、同じ枠の中で「上から下、同じ高さ(機器の高さの半分以内のずれ)なら左から右」の順に後ろにある機器の、同じポートグループ(信号・向きも同じ)の空きポートへ続きます。たとえばアンプの出力を複数選び、枠の中に並べたスピーカーの先頭に落とすと、スピーカー1台ずつに順につながります。対応するポートを持たない機器は飛ばし、枠の外の機器や、落とした機器より前の機器へは進みません。ドラッグ中は、落とし先の枠が点線で囲まれます。枠に入っていない機器は、これまでどおり1台の中だけです。

つなげないもの(接続しない): すでに接続済みのポート、相手の空きポートが足りない分、信号の種類が違う組、入力同士・出力同士の組。入力と出力が混ざった選択は、全体を接続しません。1本ずつなら、信号違いや入力同士でも警告つきで接続できます。Esc(または何もない場所のクリック)で選択を解除、ドラッグ中の Esc で取り消せます。

## 6. 確認事項

次の接続は、禁止せずに「確認事項」として知らせます。

- 信号の種類が違うポート同士(線は**点線**)
- 入力同士、または出力同士(線は**破線**)。「入出力」のポートは、どちらとも組めます。

ツールバーの「確認事項 N」に件数が出ます。クリックすると、一覧(機器名とポート名、理由)が右パネルに出ます。項目を押すと、該当の線が選ばれます。直すと、自動で一覧から消えます。

破線と点線は作業用の目印です。SVG/PNG出力では、実線で出力します。

## 7. 枠(グループ)

- パレットの「枠(グループ)」で追加します。枠線をクリックすると選べます。
- 枠を**ドラッグ**すると、**枠の中にある機器も一緒に動きます**。角や辺の**ハンドル**で、大きさを変えます(中の機器は動きません)。
- パネルで、枠の名称を編集できます。
- **所属は、見た目で決まります**。機器の中心が枠の中にあれば、その枠の所属です。枠の中へ動かせば入り、外へ出せば外れます。参加・離脱の操作は要りません。枠が入れ子なら、内側の枠の所属です。
- 枠を削除しても、中の機器は残ります。

## 8. 凡例(信号の種類)の編集

何も選んでいないときの右パネルで、信号の種類を編集します。

- 名称と色の変更、並べ替え、追加、削除ができます。色を変えると、図の線・ポート・凡例が一度に変わります。
- 使われている種類は、削除できません(ポートが使っている場合と、機器の種類の定義が参照している場合)。
- 名称を変えても、内部のIDは変わらないので、接続は切れません。
- 標準は、LAN・CONTROL・HDMI・USB・AUDIO の5種類です。

## 9. 保存・読み込み・出力

| 操作 | 内容 |
|---|---|
| 保存 / 開く | 図をJSONファイルで保存・読み込みします。Ctrl+S でも保存できます |
| SVG出力 | 文字を本物のテキストで出力します。PowerPoint などに貼れます。凡例付き |
| PNG出力 | 2倍の解像度の画像です。凡例付き |
| 機器一覧(CSV) | 名称・型番・台数・種類・ポート数・場所(属する枠の名称)。同じ機器は1行にまとめ、台数を合計します。Excelで開けます |

未保存の変更があるまま「新規」「開く」を選ぶと、確認が出ます。

### 機器一覧(CSV)を読み込む

見積や機器表(Excelなど)から、図の下書き(機器と枠)を作れます。ツールバーの「機器一覧を読み込む」でCSVを選びます。**接続は作りません**(接続は図の上で引きます)。今ある図には**追加**されます(置き換えません)。追加の前に確認が出て、追加は**元に戻す1回**で全部戻ります。

**CSVの作り方**: まず「機器一覧(CSV)」で書き出し、1行目(見出し)はそのままに、行を書き換えたり足したりします。見本は [docs/sample_devices.csv](sample_devices.csv) です。

| 見出し(日本語 / 英語) | 内容 |
|---|---|
| 名称 / Name(**必須**) | 機器の名前 |
| 型番 / Model | 型番 |
| 台数 / Quantity | 1〜999の整数(空なら1)。**1つの機器の台数**として入ります(台数ぶんのポートが付く) |
| 種類 / Type | 標準機器の名前(下記)。空なら汎用機器 |
| ポート数 / Ports | 整数(空でもよい)。**読み込みでは使いません**(ポート構成は種類の標準のものになります) |
| 場所 / Location | 同じ場所の機器を、同じ名前の枠にまとめます。空なら枠に入れません |

- **見出しは、上の名前(日本語または英語)と完全に同じものだけ**を受け付けます(前後の空白は無視)。「機器」「モデル」「name」などの別名は受け付けません。列の順番は自由です。
- **知らない見出しの列**(備考など)は読み込まず、確認の画面に「読み込まない列」と出ます(見出しの誤字に気づけます)。
- **種類は、標準機器の名前と完全に一致**したものだけが対応します(全角・半角、大文字・小文字は区別します。セルの前後の空白だけは無視します)。日本語: 汎用機器 / PC / タッチパネル / カメラ / マイク / スピーカ / アンプ / ディスプレイ / エンコーダ / デコーダ / スイッチ 8ポート / スイッチ 16ポート / スイッチ 24ポート / スイッチ 48ポート。英語: Generic device / PC / Touch panel / Camera / Microphone / Speaker / Amplifier / Display / Encoder / Decoder / Switch 8 ports / Switch 16 ports / Switch 24 ports / Switch 48 ports。一致しない種類(この図だけの機器の名前を含む)は**汎用機器**になり、確認の画面に出ます。
- 書き出したCSVを読み込むと、名称・型番・台数・種類・場所は保たれますが、**ポート構成は標準に戻り**、別々に置いていた同じ機器は1つの機器(台数)にまとまります。
- **配置**: 場所ごとに枠を作り、枠の中へ左から右へ折り返して並べます。今ある機器・枠の下から始め、**ページに収まらない分は置きません**(ページは大きくしません。置けなかった機器は確認の画面に出ます)。1台も置けないときは、ページを大きくするよう案内が出ます。
- **エラー**(何も追加されません): 1行目に「名称」の列がない・同じ列が2つある、名称が空の行、台数やポート数が使えない値、引用符が閉じていない。行番号つきで表示されます。
- **文字コード**: UTF-8(BOM付きを含む)と Shift_JIS を自動で判別します。Excelで「CSV(カンマ区切り)」として保存したファイルを、そのまま読み込めます。文字化けの恐れがあるときは警告が出ます。
- 書き出しは、先頭が `=` `+` `-` `@` の値の前に `'` を付けます(表計算ソフトで数式として実行されないため)。読み込みでは、この `'` を取り除いて元に戻します。

## 10. キーボード操作

| キー | 動作 |
|---|---|
| Ctrl+Z | 元に戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直し |
| Ctrl+C / Ctrl+V | 選んだ機器・枠のコピー / 貼り付け |
| Ctrl+D | 選んだ機器・枠をその場に複製 |
| Ctrl+S | 保存 |

## 11. 既知の制約

- 図は1ページだけです。複数ページには対応していません。
- 機器のアイコンは標準のものだけです(自分の画像の取り込みは未対応)。
- 線の経路を、手で調整する機能はありません。
- 大きさの上限があります(画面が固まるのを防ぐためです)。1機器あたり: 台数1〜999、ポートの合計5000個まで。1ページあたり: 機器2000台、ポートの合計20000個、接続20000本まで。図のファイルは20MB、機器一覧のCSVは5MB(データ行は10000行)までです。上限を超えるファイルは読み込めません。
- 枠をドラッグしている間は、中の機器がついてこず、ドロップした時点で一斉に動きます。
- Firefox・Safari での動作は、確認していません。
- PowerPoint 向けの直接の出力(.pptx)は未対応です。SVG出力を貼り付けてください。
